The same botanical family app, with a private server connection to your existing Google Sheet. Children use their family name and code; their browser does not need to open Google services.

Ready to deploy; not live yet. You will connect your parent-owned Google, GitHub and Render accounts. Start with the complete Family_Tasks_Hosted.zip package downloaded alongside this guide. Keep your existing Sheet and do not run setupHousehold again.

STEP 1 · KEEP YOUR EXISTING SHEET

Add the private hosting connection.

  1. Open your current Google Sheet → Extensions → Apps Script.
  2. Replace the contents of Code.gs with the updated backend code below, then Save. Your existing Index.html can stay in Apps Script. Do not run setupHousehold.
  3. Select showHostingConnection in the function dropdown and click Run. Return to the Sheet and copy the hosting connection secret shown in the dialog. Or reload the Sheet and use Family Tasks → Show hosting connection secret.
  4. Choose Deploy → New deployment → Web app. Name it Family Tasks hosted connection. Set Execute as: Me and Who has access: Anyone, allowing anonymous requests.
  5. Deploy and copy the new /exec URL. You will use it on the server, together with the hosting secret. A new deployment leaves the old deployed app available while you test.

The hosting secret is separate from the family access codes. Running showHostingConnection again shows the same secret without changing family accounts.

STEP 2 · PREPARE THE WEBSITE FILES

Put the app in a private repository.

  1. Extract Family_Tasks_Hosted.zip.
  2. In your parent-owned GitHub account, create a private repository called family-tasks.
  3. Choose Add file → Upload files. Upload the contents of the extracted Family_Tasks_Hosted folder, keeping its subfolders intact, and commit the upload.
  4. Check that package.json, server.mjs and render.yaml appear at the repository’s top level.

Your actual hosting secret belongs only in Render’s environment settings. Do not put it into the repository, a public file or chat.

STEP 3 · CREATE A WEB SERVICE

Publish the separate family website.

  1. Open your Render dashboard, choose New → Web Service, and connect the private repository.
  2. Use the settings below and choose the hosting plan you want. A Free web service may take about a minute to wake after inactivity.
  3. Add the private environment values before deploying. Render automatically supplies the website address and port.

STEP 4 · INVITE YOUR FAMILY

A new address. The same family garden.

  • Sign into the new hosted website using your existing administrator name and family access code.
  • Confirm your tasks, members, votes and history are present.
  • Open the new hosted website on your child’s device. Approve that specific website in Family Link if requested.
  • Use the child’s existing family name and access code. They should not receive a Google sign-in prompt.
  • If a Google age message appears, check the address bar: children should use the new website, not a Google Sheet or /exec address.

The app keeps device supervision in place. Actual Google deployment, hosting credentials and your child’s device still need to be tested in your accounts.
